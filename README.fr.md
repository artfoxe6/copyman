# CopyManager Pro - Gestionnaire de presse-papiers multiplateforme

CopyManager Pro est un gestionnaire de presse-papiers axé sur la confidentialité local-first. Il offre un historique du presse-papiers et une recherche rapide sur macOS, Windows et Linux.

Site web : https://cpman.20480101.xyz

## Fonctionnalités principales

- Recherche globale style Spotlight : champ flottant minimaliste, disponible à la demande sans casser le flux.
- Recherche en millisecondes : préchargement mémoire + combinaisons de mots-clés (ex. "code login") pour retrouver des contenus de minutes ou de mois.
- Commandes personnalisées : exécutez des scripts Python / Shell / Node.js sur les données du presse-papiers comme une pipeline de traitement.
- Conversion instantanée : préfixes de commande (ex. `>json`) pour formater, changer la casse, etc.
- Tableau de bord d'efficacité : statistiques visuelles par jour, mois et année.
- Gestion du stockage : visualisation de l'usage base de données/médias et nettoyage en un clic.
- Support de contenu complet : texte brut, rich text, images et chemins de fichiers, classés par type.
- Améliorations image/fichier : miniatures avec double-clic pour l'original ; copies de fichiers avec chemins enregistrés.
- Sauvegarde et migration : export/import de l'historique et des ressources images sans perte.
- Confidentialité local-first : les données restent sur l'appareil, jamais envoyées.
- Personnalisation : personnalisation complète des couleurs et des thèmes.

## Raccourcis rapides

- Ouvrir la fenêtre : `Ctrl+Shift+M` (ou `Cmd+Shift+M`)
- Coller et masquer automatiquement : `Enter`
- Fermer instantanément : `Esc`

## Cas d'usage

- Développeurs, designers, ops et bureaux avec beaucoup de copier/coller
- Équipes ayant besoin d'un historique multiplateforme et d'une recherche rapide
- Utilisateurs soucieux de la confidentialité et des données locales
