## 核心功能与亮点

- Spotlight 风格全局搜索：极简悬浮搜索框，随叫随到、随挥即隐，不卡顿、不打断工作流。
- 毫秒级闪电搜索：内存预加载 + 关键词组合检索（例如“code login”），无论是几分钟前的内容还是数月前的内容，都能瞬间找到。
- 自定义命令系统：支持 Python / Shell / Node.js 脚本处理剪贴板内容，实现“剪贴板即数据处理流水线”的效率升级。
- 即时文本转换：通过命令前缀（如 `>json`）完成格式化、大小写转换等操作，结果即时可粘贴。
- 效率仪表盘：可视化统计每日/每月/每年使用趋势，量化节省时间与效率提升。
- 存储管理：清晰展示数据库与媒体资源占用，提供一键清理工具，轻装上阵。
- 全内容支持：纯文本、富文本、图片、文件路径等均可记录并按类型分类展示。
- 图片与文件增强：图片缩略图预览，双击原图；文件复制记录路径，快速定位来源。
- 数据备份与迁移：一键导入/导出历史与图片资源，换机或备份都能无损迁移。
- 本地优先与隐私保护：数据仅存本地，从不上传云端。
- 个性化主题：全量颜色自定义与主题体验，界面与你的审美保持一致。

## 关键操作（上手更快）

- 呼出窗口：`Ctrl+Shift+M`（或 `Cmd+Shift+M`）
- 回车粘贴并自动隐藏：`Enter`
- 立即关闭：`Esc`
