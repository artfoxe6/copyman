# CopyManager Pro — кроссплатформенный менеджер буфера обмена

CopyManager Pro — менеджер буфера обмена с упором на локальную приватность. Он обеспечивает историю буфера и быстрый поиск на macOS, Windows и Linux.

## Ключевые возможности

- Глобальный поиск в стиле Spotlight: минималистичное плавающее поле, появляется по требованию и не сбивает поток.
- Поиск за миллисекунды: предзагрузка в памяти + комбинации ключевых слов (например, "code login") для поиска от минут до месяцев.
- Пользовательские команды: скрипты Python / Shell / Node.js обрабатывают данные буфера как конвейер.
- Мгновенная конвертация текста: префиксы (например, `>json`) для форматирования и смены регистра.
- Панель эффективности: визуальная статистика по дням, месяцам и годам.
- Управление хранилищем: прозрачное использование базы и медиа + очистка в один клик.
- Поддержка всего контента: обычный текст, rich text, изображения и пути файлов, с группировкой по типу.
- Улучшения для изображений и файлов: миниатюры, двойной клик для оригинала; копии файлов сохраняют пути.
- Резервное копирование и миграция: экспорт/импорт истории и изображений без потерь.
- Локальная приватность: данные хранятся на устройстве и не загружаются.
- Персонализация: полная настройка цветов и тем.

## Горячие клавиши

- Открыть окно: `Ctrl+Shift+M` (или `Cmd+Shift+M`)
- Вставить и скрыть автоматически: `Enter`
- Закрыть сразу: `Esc`
