# CopyManager Pro - 크로스 플랫폼 클립보드 관리자

CopyManager Pro는 로컬 우선 개인정보 보호에 초점을 맞춘 클립보드 관리자입니다. macOS, Windows, Linux에서 클립보드 기록 관리와 빠른 검색을 제공합니다.

웹사이트: https://cpman.20480101.xyz

## 주요 기능

- Spotlight 스타일 전역 검색: 필요한 순간에 뜨는 미니멀한 플로팅 검색창으로 작업 흐름을 끊지 않습니다.
- 밀리초급 빠른 검색: 메모리 프리로드 + 키워드 조합(예: "code login")으로 몇 분 전부터 몇 달 전까지 즉시 찾기.
- 사용자 정의 명령: Python / Shell / Node.js 스크립트로 클립보드 데이터를 처리.
- 즉시 텍스트 변환: `>json` 같은 접두어로 포맷팅, 대소문자 변환 등을 빠르게 수행.
- 효율 대시보드: 일/월/년 단위의 시각화 통계.
- 스토리지 관리: 데이터베이스/미디어 사용량을 명확히 표시하고 원클릭 정리.
- 전체 콘텐츠 지원: 일반 텍스트, 리치 텍스트, 이미지, 파일 경로를 유형별로 관리.
- 이미지/파일 강화: 썸네일 미리보기, 더블클릭 원본 보기. 파일 복사는 경로 기록.
- 백업 및 마이그레이션: 기록과 이미지 리소스를 내보내기/가져오기하여 무손실 이전.
- 로컬 우선 프라이버시: 데이터는 기기에만 저장되고 업로드되지 않습니다.
- 개인화: 전체 색상 커스터마이징과 테마 지원.

## 빠른 단축키

- 창 열기: `Ctrl+Shift+M` (또는 `Cmd+Shift+M`)
- 붙여넣고 자동 숨김: `Enter`
- 즉시 닫기: `Esc`

## 사용 시나리오

- 복사/붙여넣기가 잦은 개발자, 디자이너, 운영, 사무 업무
- 크로스 플랫폼 기록 관리와 빠른 검색이 필요한 팀
- 프라이버시를 중시하고 로컬 데이터 관리를 선호하는 사용자
