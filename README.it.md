# CopyManager Pro - Gestore di appunti multipiattaforma

CopyManager Pro è un gestore di appunti con attenzione alla privacy local-first. Offre cronologia degli appunti e ricerca rapida su macOS, Windows e Linux.

Sito web: https://cpman.20480101.xyz

## Funzionalità principali

- Ricerca globale in stile Spotlight: casella flottante minimalista disponibile al bisogno senza interrompere il flusso.
- Ricerca in millisecondi: pre-caricamento in memoria + combinazioni di parole chiave (es. "code login") per trovare contenuti di minuti o mesi.
- Comandi personalizzati: esegui script Python / Shell / Node.js sui dati degli appunti come una pipeline.
- Conversione testo istantanea: prefissi (es. `>json`) per formattazione, maiuscole/minuscole e altro.
- Dashboard di efficienza: statistiche visive per giorno, mese e anno.
- Gestione storage: visibilità su database e media con pulizia a un clic.
- Supporto completo dei contenuti: testo normale, rich text, immagini e percorsi file, organizzati per tipo.
- Migliorie immagini e file: anteprima miniatura con doppio clic sull'originale; copie file con percorsi registrati.
- Backup e migrazione: export/import di cronologia e risorse immagini senza perdita.
- Privacy local-first: dati solo sul dispositivo, mai caricati.
- Personalizzazione: personalizzazione completa di colori e temi.

## Scorciatoie rapide

- Apri finestra: `Ctrl+Shift+M` (o `Cmd+Shift+M`)
- Incolla e nascondi automaticamente: `Enter`
- Chiudi subito: `Esc`
