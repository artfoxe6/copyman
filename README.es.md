# CopyManager Pro - Gestor de portapapeles multiplataforma

CopyManager Pro es un gestor de portapapeles con enfoque local-first y privacidad. Ofrece historial del portapapeles y búsqueda rápida en macOS, Windows y Linux.

Sitio web: https://www.20480101.xyz

## Funciones principales

- Búsqueda global estilo Spotlight: cuadro flotante minimalista que aparece bajo demanda sin interrumpir el flujo.
- Búsqueda en milisegundos: precarga en memoria + combinaciones de palabras clave (p. ej., "code login") para encontrar elementos de minutos o meses.
- Comandos personalizados: ejecuta scripts Python / Shell / Node.js sobre los datos del portapapeles como una canalización de datos.
- Conversión de texto instantánea: usa prefijos (p. ej., `>json`) para formateo, mayúsculas/minúsculas y más.
- Panel de eficiencia: estadísticas visuales por día, mes y año.
- Gestión de almacenamiento: muestra uso de base de datos y medios con limpieza de un clic.
- Soporte de contenido completo: texto plano, texto enriquecido, imágenes y rutas de archivos, organizados por tipo.
- Mejoras para imágenes y archivos: vista previa en miniatura con doble clic al original; copias de archivos registran rutas.
- Copias de seguridad y migración: exporta/importa historial y recursos de imagen sin pérdida.
- Privacidad local-first: los datos se guardan localmente y nunca se suben.
- Personalización: personalización total de colores y temas.

## Atajos rápidos

- Abrir ventana: `Ctrl+Shift+M` (o `Cmd+Shift+M`)
- Pegar y ocultar automáticamente: `Enter`
- Cerrar al instante: `Esc`
