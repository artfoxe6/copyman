# CopyManager Pro - Gerenciador de área de transferência multiplataforma

CopyManager Pro é um gerenciador de área de transferência com foco em privacidade local-first. Oferece histórico da área de transferência e busca rápida em macOS, Windows e Linux.

## Principais recursos

- Busca global estilo Spotlight: caixa flutuante minimalista que aparece sob demanda sem interromper o fluxo.
- Busca em milissegundos: pré-carregamento em memória + combinações de palavras-chave (ex.: "code login") para encontrar itens de minutos ou meses.
- Comandos personalizados: scripts Python / Shell / Node.js para processar dados da área de transferência como uma pipeline.
- Conversão de texto instantânea: prefixos (ex.: `>json`) para formatação, maiúsculas/minúsculas e mais.
- Painel de eficiência: estatísticas visuais por dia, mês e ano.
- Gerenciamento de armazenamento: uso de banco de dados/mídia e limpeza com um clique.
- Suporte completo de conteúdo: texto simples, rich text, imagens e caminhos de arquivo, organizados por tipo.
- Melhorias de imagem/arquivo: miniaturas com duplo clique no original; cópias de arquivos registram caminhos.
- Backup e migração: exportar/importar histórico e recursos de imagem sem perda.
- Privacidade local-first: dados ficam no dispositivo e nunca são enviados.
- Personalização: personalização completa de cores e temas.

## Atalhos rápidos

- Abrir janela: `Ctrl+Shift+M` (ou `Cmd+Shift+M`)
- Colar e ocultar automaticamente: `Enter`
- Fechar rapidamente: `Esc`
