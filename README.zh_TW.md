# CopyManager Pro - 跨平台剪貼簿管理器

CopyManager Pro 是一款剪貼簿管理器（Clipboard Manager），重視本地優先與隱私保護，提供剪貼簿歷史管理與快速檢索能力，支援 macOS、Windows 與 Linux。

## 核心功能與亮點

- Spotlight 風格全域搜尋：極簡懸浮搜尋框，隨叫隨到、隨揮即隱，不卡頓、不打斷工作流。
- 毫秒級閃電搜尋：記憶體預載 + 關鍵字組合檢索（例如「code login」），無論是幾分鐘前的內容還是數月前的內容，都能瞬間找到。
- 自訂命令系統：支援 Python / Shell / Node.js 腳本處理剪貼簿內容，實現「剪貼簿即資料處理流水線」的效率升級。
- 即時文字轉換：透過命令前綴（如 `>json`）完成格式化、大小寫轉換等操作，結果即時可貼上。
- 效率儀表板：視覺化統計每日/每月/每年使用趨勢，量化節省時間與效率提升。
- 儲存管理：清楚顯示資料庫與媒體資源占用，提供一鍵清理工具，輕裝上陣。
- 全內容支援：純文字、富文字、圖片、檔案路徑等均可記錄並按類型分類展示。
- 圖片與檔案增強：圖片縮圖預覽，雙擊原圖；檔案複製記錄路徑，快速定位來源。
- 資料備份與遷移：一鍵匯入/匯出歷史與圖片資源，換機或備份都能無損遷移。
- 本地優先與隱私保護：資料僅存本地，從不上傳雲端。
- 個人化主題：全量顏色自訂與主題體驗，介面與你的審美一致。

## 關鍵操作（上手更快）

- 呼出視窗：`Ctrl+Shift+M`（或 `Cmd+Shift+M`）
- 回車貼上並自動隱藏：`Enter`
- 立即關閉：`Esc`
