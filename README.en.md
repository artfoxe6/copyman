# CopyManager Pro - Cross-Platform Clipboard Manager

CopyManager Pro is a clipboard manager focused on local-first privacy. It provides clipboard history management and fast search across macOS, Windows, and Linux.

## Key Features

- Spotlight-style global search: a minimalist floating search box that appears on demand without breaking your flow.
- Millisecond-fast search: memory preloading plus keyword combinations (e.g., "code login") to find items from minutes or months ago.
- Custom commands: run Python / Shell / Node.js scripts on clipboard data to turn the clipboard into a data-processing pipeline.
- Instant text conversion: use command prefixes (e.g., `>json`) for formatting, case conversion, and more.
- Efficiency dashboard: visual stats by day, month, and year to quantify productivity.
- Storage management: clear database/media usage and one-click cleanup.
- Full content support: plain text, rich text, images, and file paths, organized by type.
- Image and file enhancements: thumbnail previews with double-click for the original; file copies record paths for quick source access.
- Backup and migration: export/import history and image assets for lossless moves.
- Local-first privacy: data stays on your device and is never uploaded.
- Personalization: full color customization and themes.

## Quick Shortcuts

- Open window: `Ctrl+Shift+M` (or `Cmd+Shift+M`)
- Paste and auto-hide: `Enter`
- Close instantly: `Esc`

- Developers, designers, operations, and office workers who copy/paste frequently
- Teams that need cross-platform clipboard history and fast search
- Privacy-conscious users who prefer local data management
